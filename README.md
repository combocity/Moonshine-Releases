# Moonshine

## Download

- [Windows x64](https://github.com/combocity/Moonshine-Releases/releases/download/v0.1.3/ComboCity.Moonshine-win-Portable.zip)
- [Linux x64](https://github.com/combocity/Moonshine-Releases/releases/download/v0.1.3/ComboCity.Moonshine.AppImage)

The other release files are used by the automatic updater.

## Run on Linux

Open a terminal in the directory containing the AppImage, then run:

```bash
chmod +x ComboCity.Moonshine.AppImage
./ComboCity.Moonshine.AppImage
```
